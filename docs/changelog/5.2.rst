.. changelog::
  :version: 5.2.0-alpha1
  :released: 27th of November 2026

  It provides many small new features and improvements, as well as the
  usual truckload of bug fixes.

  Please review the :doc:`Upgrade Notes <../upgrading>` before upgrading from versions < 5.2.x.
